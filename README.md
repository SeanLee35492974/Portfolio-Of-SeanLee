# 李轩然｜企业文化 / 企业宣传 Portfolio V0

这是一个无需构建工具、可直接打开的静态 Portfolio 原型。

## 文件结构

- `index.html`：首页，沿用已冻结的 V1 结构：Hero → 四项定位数据 → 精选案例 → Experience / About / Contact。
- `case-template.html`：可复用的九段式案例页模板。
- `case-lingdong.html`：第一个深度案例——“凌动官网品牌内容与视觉优化”。
- `case-lingdong-people.html`：第二个深度案例——“《凌动百工志》员工人物栏目”。
- `case-guowei.html`：第三个深度案例——“国微电子 HR与企业文化重点项目传播”。
- `styles.css`：全局视觉系统、响应式布局与案例组件。
- `script.js`：滚动出现、导航状态和邮箱复制的小交互。
- `李轩然_企业文化企宣简历_正式版.docx` / `.pdf`：首页“下载简历”按钮对应的简历文件。

## 视觉系统 V1

- 基调：Soft Blue Editorial / Structured Playfulness
- 比例：90% 规整 + 10% 克制手绘
- 底色：暖白纸张感
- 主色：深海军蓝；重点色：蓝色光谱，并保留少量蓝紫 / 粉雾化渐变
- 质感：轻雾状渐变、细线、圆角卡片与大留白
- 网格：桌面端双栏 / 三栏，移动端单栏，所有内容保持可读优先
